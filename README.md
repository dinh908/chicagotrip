# Group Expense Manager

Ứng dụng web đơn giản để quản lý chi tiêu nhóm, cho phép:
- Thêm/xóa thành viên.
- Ghi nhận nạp quỹ và chi tiêu.
- Tính toán số dư và gợi ý thanh toán.

## Công nghệ
- Vue.js
- Tailwind CSS
- Font Awesome

## Cách chạy
1. Tải repository về máy.
2. Mở file `index.html` trong trình duyệt.

## Kế hoạch phát triển
- Thêm tính năng đăng nhập admin.
- Tích hợp lưu trữ dữ liệu đám mây.
- Xuất báo cáo Excel.
